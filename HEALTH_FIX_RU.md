# Исправление «Инвайты и цели — Ошибка»

После установки этой версии `/админ здоровье` показывает конкретную аномалию и ID записи.

Для безопасного исправления через кнопки:

1. Откройте главную панель.
2. `⚙️ Админ` → `🗄️ База` → `🩺 Диагностика`.
3. Прочитайте найденные записи.
4. Если доступна однозначная legacy-ошибка, нажмите `🧹 Исправить безопасные`.
5. Повторно запустите `🩺 Здоровье`.

### Что исправляется автоматически

- Исторический self-invite (`invites.user_id == invites.invited_by`): запись НЕ удаляется. Поле `user_id` очищается, а статик, имя, чек-лист, `invited_by`, статус, заметки и логи остаются.
- Legacy goal с `current_value=NULL`: значение становится `0`.

### Что автоматически НЕ исправляется

Дубли активных инвайтов/целей, неизвестные статусы, некорректные checklist-значения и другие неоднозначные записи только показываются с ID. Их нельзя безопасно менять без решения администратора.

# Короткая проверка после обновления

1. Не загружать `.env` и `recruiter_bot.db` в GitHub.
2. На хосте сохранить `DATABASE_PATH=data/recruiter_bot.db` и `TIMEZONE=Europe/Moscow`.
3. Перед обновлением сделать `/админ бэкап`.
4. Обновить код: GitHub → Stop → Rebuild → Start.
5. Выполнить `/админ здоровье` и `/админ время`.
6. Проверить смену на 3 места: ранний старт одного участника не должен закрыть запись до официального начала.
7. После официального начала запись и самостоятельный выход должны закрыться.
8. Проверить reject → исправление → approve отчёта.
9. Проверить инвайт через панель: выбранные пункты должны отображаться `✅/⬜`.
10. Проверить бэкап ещё раз после smoke-test.

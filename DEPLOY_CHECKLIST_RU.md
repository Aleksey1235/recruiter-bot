# Финальный deployment checklist

1. На старой версии выполнить `/админ бэкап` и скачать файл.
2. Остановить бота на хосте.
3. **Не удалять и не заменять** рабочую `data/recruiter_bot.db`.
4. В GitHub обновить только код из финального архива. Не загружать `.env`, `*.db`, `*.db-wal`, `*.db-shm`, `bot.log`.
5. Проверить ENV: `DATABASE_PATH=data/recruiter_bot.db`, `TIMEZONE=Europe/Moscow`, `PANEL_CHANNEL_ID=...` и все ID ролей/каналов.
6. На хосте: Stop → Rebuild → Start.
7. После старта выполнить `/админ здоровье`. Ожидается schema v4 и зелёные проверки БД, смен, инвайтов/целей, ЧС, финансов, уведомлений, каналов/ролей и фоновых задач.
8. Проверить, что постоянная панель одна и находится в отдельном `PANEL_CHANNEL_ID`.
9. Выполнить короткий smoke-test смены, reject→resubmit→approve отчёта, обычного инвайта и заблокированного ЧС-инвайта.
10. Проверить права ЧС: управление доступно только Admin; Senior не должен иметь кнопок/команд ЧС. Снятие требует обязательную причину.
11. После smoke-test выполнить `/админ бэкап` ещё раз.

Если `/админ здоровье` показывает ошибку, не удаляйте БД. Откройте **Админ → База → 🩺 Диагностика**: новая версия показывает конкретные ID проблемных записей.

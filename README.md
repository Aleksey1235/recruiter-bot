# Recruiter Bot v6.1 — DeSanta / ECLIPSE

Обновление существующего Discord-бота отдела рекрутов. Python 3.11,
disnake 2.12.1, SQLite schema v6. Производственные зависимости сохранены.

## Исправление v6.1

Личные ответы кнопок создаются отдельными скрытыми сообщениями и не заменяют
общую панель или карточку смены. При запуске восстанавливается панель,
которую v6 могла заменить меню рекламы, и удаляются личные результаты записи
с недавних карточек смен. Состав участников и статусы берутся из прежней БД.
Проверены ограничения доступа обычного рекрута к руководству, админке,
проверке отчётов/инвайтов/рекламы, вложенным меню и формам.

Для установки исправления поверх работающей v6: **HOTFIX_6_1_RU.md**.
Схема БД остаётся v6. Новых функций и настроек это исправление не добавляет.

## Что изменено

- Учёт рекламы семьи DeSanta через кнопки: предварительный случайный выбор
  фото-проверки (20%), интервал зафиксированных публикаций 3 минуты.
- Фото загружаются в форму по кнопке. Бот хранит копии в одном закрытом канале
  Discord, а на хосте — только метаданные. Senior/Admin проверяют фото позже.
- Статистика различает отметки без проверки и подтверждённые фото. Ожидающие
  проверки не засчитываются до одобрения.
- Профиль показывает рекламу за всё время, еженедельный отчёт — за свою неделю.
- В прежнее меню целей добавлено количество реклам за день, неделю или месяц.
  Прогресс учитывает только зачтённые публикации.
- Проверенные фото удаляются через 90 дней, статистика сохраняется.
- Запись на смену без ввода статика; сохранённые статики остаются.
- Профиль создаётся при первом нажатии основной панели участником с нужной ролью.

Полный список, ограничения и защита от сбоев: **RELEASE_CHANGES_RU.md**.

## Обновление работающего бота

Прочитайте **DEPLOY_CHECKLIST_RU.md**. Не заменяйте рабочую БД или `.env`
содержимым архива. Скачайте консистентный backup, остановите бота и проверьте
постоянный диск/volume. При первом запуске схема обновится до v6.

Для включения рекламы дополните окружение:

```env
ADS_REVIEW_CHANNEL_ID=ID_ОТДЕЛЬНОГО_ЗАКРЫТОГО_ТЕКСТОВОГО_КАНАЛА
ADS_FAMILY_NAME=DeSanta
ADS_CHECK_PERCENT=20
ADS_INTERVAL_MINUTES=3
ADS_RETENTION_DAYS=90
```

Канал должен быть отдельным от прежних служебных каналов, закрытым для
@everyone и обычной роли Recruiter. Senior/Admin и бот должны иметь доступ.
Боту нужны View Channel, Send Messages, Embed Links, Attach Files и
Read Message History. У обычных рекрутеров не должно быть Manage Messages.

Если `ADS_REVIEW_CHANNEL_ID=0` или отсутствует, действия рекламы выключены,
но остальные функции продолжают работать. DeSanta / 20 / 3 / 90 — значения
по умолчанию. Не заменяйте прежние переменные окружения.

## Работа рекрутера

1. «Взять смену» — запись сразу, без формы статика.
2. «Панель → Смена → Начать».
3. До подачи: «Панель → Реклама → Подать рекламу».
4. После выхода объявления: «Опубликовано» либо скриншот → «Прикрепить фото».
5. История и статистика — в том же разделе. «Текущая попытка» восстанавливает
   прежнее решение о фото после закрытия меню или перезапуска.

Senior/Admin: «Реклама → Ожидают проверки» либо кнопки карточки в новом канале.
Проверка собственной рекламы запрещена.
В прежнем разделе управления целями выберите тип «Рекламы», период и число.
Рекрутер видит выполнение через «Мои цели».

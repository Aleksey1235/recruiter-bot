# Чёрный список Recruiter Bot

## Права

- **Только Admin**: добавить, дополнить, поиск, активный список, история и снять с ЧС.

## Что хранится

- Discord ID;
- сохранённый Discord-тег;
- статик;
- имя / фамилия;
- причина;
- доказательство / ссылка;
- заметка;
- кто и когда добавил;
- статус `active` / `removed`;
- кто, когда и по какой причине снял.

История физически не удаляется. После снятия можно позже создать новую активную запись на того же человека, при этом старая остаётся в истории.

## Инвайты

Активный ЧС блокирует инвайт по Discord ID **или** по статику. Проверка выполняется и при создании, и повторно при одобрении. Поэтому добавление человека в ЧС после создания pending-инвайта всё равно не позволит его принять. Финансовое начисление при блокировке не создаётся.

## Панель

`⚙️ Админ → 🚫 Чёрный список`:

- `➕ Добавить` — выбор пользователя Discord, затем статик / имя / причина / доказательство / заметка;
- `🆔 Добавить по ID` — если человека уже нет на сервере;
- `🔎 Найти` — Discord ID / статик / тег / имя;
- `📋 Активный ЧС`;
- `📜 История`;
- `♻️ Снять с ЧС` — причина снятия обязательна.

## Диагностика

`/админ здоровье` имеет отдельный пункт **Чёрный список**. Проверяются обязательные поля, статус, корректность данных о снятии и отсутствие дублей среди активных Discord ID/статиков.

`Админ → База → Диагностика` также показывает конкретные ID проблемных записей. Существующая система безопасного исправления legacy-инвайтов/целей сохранена.
